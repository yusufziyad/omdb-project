## Overview
This project is a fully responsive Single Page Application (SPA) built for a web development assignment. It consumes the OMDB API to search and display movie details.

## Features Implemented
* **Movie Search:** Users can search for movies by entering a title.
* **Movie Details:** Displays the Title, Year, Genre, Director, and Poster of the searched movie.
* **Error Handling:** Shows a clear error message if the movie is not found or if the search box is empty.
* **Persistent Search:** The last searched movie is saved using `LocalStorage` and is retained even if the page is refreshed.
* **Responsive Design:** The layout adapts to mobile and desktop screens automatically.

## Technologies Used

* CSS3
